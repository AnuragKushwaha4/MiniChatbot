# Mini Chatbot

**Mini Chatbot** is a lightweight conversational AI built using **Python (Flask)** for the backend and **HTML/CSS/JavaScript** for the frontend. It uses the **Hugging Face Transformers** library to integrate with the **Facebook BlenderBot** language model. The project demonstrates how to connect a modern LLM with a custom web interface.

### 🔧 Technologies Used
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python Flask
- **Model**: `facebook/blenderbot-400M-distill` via Hugging Face Transformers
- **Others**: Flask-CORS, JSON handling

### 🚀 Features
- Simple user interface for chatting
- Stateful conversation using a history buffer
- Easy to replace the language model with other Hugging Face models (like Phi-2 or TinyLlama)
